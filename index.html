# Old-growth forests of Nova Scotia A map-based site showcasing Nova Scotia's old-growth forests. All content (names, locations, descriptions, links, directions) lives in `data.txt`, a plain pipe-delimited (|) text file sitting next to the page. Edit that file by hand -- no code, no database, no redeploying. ## How to add or edit a forest 1. Open `data.txt` in any plain text editor (or a spreadsheet program -- see below). Keep the header row exactly as-is: `Name|Lat, Long|Description|Learn more|Directions|Image paths` 2. Add a new line for a new forest, or edit an existing one, keeping the same column order, separated by the `|` character. - **Lat, Long**: one field, comma-separated, e.g. `44.442232, -65.253328` (right-click the spot on Google Maps and "Copy coordinates" to get this) - **Image paths**: just the filename, e.g. `spookswamp.jpg` -- it needs to match a photo you've added to the `images/` folder (see below) 3. Save the file. Refresh the page to see the change. **Easier editing tip:** if a description happens to contain a `|` character, replace it with something else (e.g. a dash), since `|` is what separates columns. ### Adding a new photo 1. Drop the photo file into the `images/` folder in this project. 2. In `data.txt`, type the exact filename in the "Image paths" column for that row (e.g. `mersey-river.jpg`). 3. If a photo is missing, the site just quietly skips showing an image for that forest rather than showing a broken-image icon -- so it's fine to add rows before you have the photo ready. Right now, `data.txt` includes three forests (MacFarlane Woods, Barney's River, Hurlburt Brook) whose photos haven't been added to `images/` yet. ## Publishing to GitHub Pages 1. Create a new GitHub repository and push all the files in this folder (`index.html`, `data.txt`, the `images/` folder) to it. 2. In the repo, go to **Settings > Pages**. 3. Under "Build and deployment," set Source to **Deploy from a branch**, pick your main branch and the `/ (root)` folder, then save. 4. GitHub will give you a URL like `https://yourusername.github.io/repo-name/` -- that's your live site. It updates automatically a minute or two after you push changes. ## Local preview Since the page loads `data.txt` with `fetch`, opening `index.html` directly from your file system may be blocked by the browser.
